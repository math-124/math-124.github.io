# 💻 Running Code

Many homework assignments and some labs will have an accompanying Jupyter Notebook. Jupyter allows us to write and run code within a single document, while also including explanations, images, and visualizations.

We will use [Google Colab](https://colab.research.google.com/) to run these notebooks, so you do not need to install anything on your computer. You can sign in using your U-M Google account.

## Opening a Notebook

Any lab or homework with a code component will include a **magic link** that opens its notebook directly in your browser. When you use one:

1. Click the magic link provided with the assignment.
2. Once the notebook opens in Google Colab, click **Copy to Drive**. **This is the most important step:** it creates your own editable copy and prevents you from losing your work.
3. Rename your copy if you would like.
4. Run the setup cells near the beginning of the notebook before starting the assignment.

## Working with Cells

A **cell** is the basic building block of a Jupyter Notebook. Cells can contain either code or writing. Run a code cell by clicking the play button beside it or by pressing `Shift` + `Enter`.

One of the first cells in every notebook we provide will download the files and images needed for that assignment. Other early cells may import Python packages or perform additional setup. Run these cells in order from the top of the notebook and wait for each to finish.

The notebook remembers the results of cells you have already run during the current session, so order matters. If you close the notebook, reconnect after being idle, or restart the Colab runtime, run the setup cells again before continuing. Your notebook itself will remain saved in Google Drive.
